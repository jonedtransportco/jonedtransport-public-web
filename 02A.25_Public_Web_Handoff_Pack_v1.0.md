# 02A.25 Public Web Handoff Pack v1.0

Version: 1.0  
Lifecycle: Under_Review  
Authorization state: AUTHORIZED FOR PUBLIC WEB HANDOFF PREPARATION ONLY

## Objective

Prepare the public website as a separate handoff artifact so `jonedtransport.com` can be published on a public-capable hosting target without reusing the private portal hosting path.

## Traceability inside `02A`

- follows the hosting separation decision closed in `02A.24`
- preserves the public homepage closed in `02A.20`
- preserves the public recruiting paths closed in `02A.17`, `02A.18`, `02A.19`, `02A.22`, and `02A.23`
- preserves the internal/private portal boundary regularized in `02A.16`

## 1. Included public web artifact

Prepared public web artifact:

- `joned-public-web.tar.gz`

Artifact purpose:

- deployable handoff package for the public JONED website only
- intended for a public-capable hosting target
- not intended for the private portal runtime

Artifact contents originate from the separated public web package prepared under:

- `work/02a-public-web`

## 2. Public scope included

The public handoff preserves:

- root homepage for `jonedtransport.com`
- public `Owner Operators` route
- public `Drivers` route
- public branding, company, services, recruiting, and contact presentation

## 3. Private scope excluded

The public handoff must not be used to:

- expose the internal portal publicly
- replace `portal.jonedtransport.com`
- activate internal operational workflows
- connect real backend integrations
- connect financial, document, or intake runtime systems

## 4. Recommended execution path

1. publish this public artifact to a public-capable hosting target
2. bind `jonedtransport.com` only to that public site
3. keep `www.jonedtransport.com` aligned to the root public site
4. keep `portal.jonedtransport.com` on the private portal host
5. verify the root domain opens without restricted access
6. verify the portal remains restricted

## 5. Validation expectations after deployment

Deployment is acceptable only when:

1. `jonedtransport.com` opens publicly without the ChatGPT access gate
2. `/owner-operators` renders from the public site
3. `/drivers` renders from the public site
4. `portal.jonedtransport.com` remains restricted
5. no real backend integrations are introduced during hosting cutover
