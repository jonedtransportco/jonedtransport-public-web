## Azure target selected

- subscription: `JONED Platform Production`

## Migration pattern

- hosting: Azure Static Web Apps
- identity: Microsoft Entra ID
- access mode: private / controlled
- public root remains separate from portal

## What the execution pack enforces

- `/portal*` protected behind authenticated access
- `/api/*` protected behind authenticated access
- `/`, `/owner-operators*`, `/drivers*` remain public-compatible in the shared codebase
- Entra app registration values are externalized as Azure settings
- custom domain target preserved as `portal.jonedtransport.com`

## What is intentionally not activated

- Azure SQL real
- Microsoft Graph operational
- document runtime
- payments or payroll runtime
- any production business integration

## Next controlled execution step

1. create or confirm Entra app registration
2. set `AAD_CLIENT_ID` and `AAD_CLIENT_SECRET`
3. provision Azure Static Web App in `rg-joned-platform`
4. validate private sign-in flow
5. cut `portal.jonedtransport.com` to Azure only after parity validation
